A plain CSV of your start dates — a backup that works without any server.

How should a file for import look?

One period start date per line, in the first column. A header line is optional, and any other columns are ignored.

start_date
2026-08-19
2026-09-15
2026-10-14

Dates can be written as 2026-10-14, 14/10/2026, 14.10.2026 or 14-10-2026 (day before month). Imported dates are added to the ones you already have; nothing is overwritten.
